# Morocco — The Dispatch Desk of Fez

Route each request according to the supplied cheap/expensive guide contract.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
python main.py
```

## Input and output

test-input.csv and the organizer evaluation environment.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1mx2XuTbK8JYwtaVVpHvRAgn34c1-pTML).

- [`main.py`](main.py)
