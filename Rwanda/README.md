# Rwanda — The Drying Floor at Karongi

Build the bounded tool graph expected by the organizer evaluator.

## Run

Use a separate Python environment. Run from this country directory.

```bash
python -m pip install -r requirements.txt
mkdir -p outputs
# Load graph.py using the organizer evaluator.
```

## Input and output

The supplied model/tool nodes and official graph evaluator.

Obtain task materials from the organizer task card; preserve their original filenames. Generated results belong in `outputs/` or another directory outside Git.

Organizer material: [source 1](https://drive.google.com/drive/folders/1c1tXsOOX7kX3H881Qv8l6VXv7t6xRnp8).
